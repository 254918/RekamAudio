# Rekam Audio - Internal Audio Recorder

**Rekam Audio** is a modern, privacy-focused Android application designed to capture **internal system audio** with high fidelity. Unlike traditional recorders that use the microphone, Rekam Audio taps directly into the system's audio stream, ensuring crystal-clear recordings without background noise.

## ✨ Key Features

*   **📱 Pure Internal Audio**
    *   Records system sound directly (Games, Music, Videos).
    *   No microphone interference or background noise.
    *   **Note:** Requires Android 10+ (API 29).

*   **🎨 Material You Design**
    *   Beautiful, modern UI capable of Dynamic Colors.
    *   Adapts to your device's wallpaper and theme (Light/Dark mode).
    *   Includes Themed App Icons.

*   **🔘 Floating Overlay Controls**
    *   Start and stop recordings from *any* app using a minimal floating button.
    *   No need to switch back and forth between apps to manage capture.

*   **📂 Built-in Manager**
    *   Complete management suite within the app.
    *   **Play** recordings instantly.
    *   **Rename** files for better organization.
    *   **Share** directly to social media or cloud storage.
    *   **Delete** unwanted takes.

*   **🔒 Privacy First**
    *   **100% Offline:** No internet permission required. Your recordings never leave your device unless you share them.
    *   **Transparent Permissions:** Only requests what is needed (Audio, Notification, Overlay).

## 🛠️ Technical Stack
*   **Language:** Kotlin
*   **UI Toolkit:** Jetpack Compose (Material 3)
*   **Architecture:** MVVM + Clean Architecture
*   **Audio Engine:** MediaProjection API + AudioRecord
*   **Target SDK:** Android 14 (API 34)

## 📥 Installation
1.  Download the latest APK from the [Releases](#) page.
2.  Install on your Android device (Android 10 or newer required).
3.  Grant the necessary permissions (Notification for controls, Overlay for the floating button).
